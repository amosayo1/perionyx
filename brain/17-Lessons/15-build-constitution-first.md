# Build the Constitution First

**Category**: Product / Startup

**Lesson**: The 5 constitutions (Governance, Product, Autonomous Finance, Experience, Workflow) prevent drift. Write the rules before writing the code. Without constitutions, every feature becomes a debate about principles. With constitutions, the answer is already documented — you just have to read it. The Brain Constitution itself is an example: it governs this vault's content with clear rules that prevent chaos.

**When it applies**: At the very start of any project, before any code is written. Define what the project is, what it isn't, and what principles guide decisions. Revisit the constitution quarterly — it should evolve, not calcify.
