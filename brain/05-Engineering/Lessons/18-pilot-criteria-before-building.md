# Pilot Criteria Must Be Defined Before Building

**Category**: Product / Startup

**Lesson**: No pilot criteria were defined for Perionyx. This means there's no clear answer to "Are we ready for a pilot?" The missing criteria include: minimum feature set, minimum data requirements, user onboarding flow, support SLA, and success metrics. Define these before building the pilot infrastructure, not after. Building without criteria means you'll never feel ready.

**When it applies**: At the start of any product, before the first external user. Define what "pilot-ready" means in concrete, measurable terms. Write it down. Revisit monthly.
