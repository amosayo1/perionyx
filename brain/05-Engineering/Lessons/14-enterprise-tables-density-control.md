# Enterprise Tables Need Density Control

**Category**: UX

**Lesson**: CFOs viewing a cash position table want compact rows — more data, less whitespace. Controllers reviewing audit logs want comfortable spacing for readability. One density doesn't fit all. The EnterpriseTable supports three density modes (comfortable, default, compact) controlled by a toolbar toggle, persisted in saved views. The ultra-compact mode is purpose-built for financial data where every pixel of information density matters.

**When it applies**: When building data tables for financial or enterprise users. Always include density controls. Default to comfortable for general use; provide compact for power users.
