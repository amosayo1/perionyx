# Security Audits Before Launch Are Non-Negotiable

**Category**: Security

**Lesson**: The Phase 16 audit found 295 findings across 23 specialist agents. Doing this before any customer sees the product was critical — fixing these issues in production, with real customer data, under time pressure, would have been catastrophic. Never skip security for speed. The audit took significant effort but prevented existential risk.

**When it applies**: Before any production deployment, customer pilot, or beta launch. Schedule a comprehensive security review at least 2 weeks before any external exposure.
