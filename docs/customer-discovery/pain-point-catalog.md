## Severity Definitions

| Level | Definition | Action Required |
|---|---|---|
| Critical | Blocks workflow; no workaround | Immediate investigation |
| Major | Significant friction; poor workaround | Address this quarter |
| Minor | Annoyance; acceptable workaround | Address this year |

## Status Definitions

| Status | Definition |
|---|---|
| Identified | Pain point captured but not yet validated |
| Validated | Confirmed by ≥2 independent sources |
| Prioritized | Added to roadmap with priority assigned |
| Addressed | Solution shipped and available |
| Resolved | Confirmed resolved via follow-up interview |
| Accepted | Deliberately not solving (documented rationale) |

## Adding a New Pain Point

1. Assign the next sequential ID: `{CATEGORY}-{NNN}` (e.g., `MEC-001`)
2. Fill all required fields
3. Link to the Interview ID from the interview template
4. Set status to `Identified`
5. Update the Recurring Theme summary table

### Template

```
| {ID} | {Title} | {Description} | {Severity} | {Frequency} | {Persona} | {Source} | {Status} |
```
