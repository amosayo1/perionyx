# Consolidation KPIs

## Key Performance Indicators

| KPI | Formula | Target | Category |
|---|---|---|---|
| Days to Consolidate | (Close Date - Period End) | < 10 days | Speed |
| Elimination Rate | (Eliminated / Total IC) × 100 | 100% | Quality |
| Adjustment Approval Rate | (Approved / Total Adjustments) × 100 | 100% | Efficiency |
| Entity Submission Rate | (Submitted / Total Entities) × 100 | 100% | Coverage |
| Audit Trail Completion | (Completed Steps / Total Steps) × 100 | 100% | Compliance |
| Unmatched IC Transactions | Count | 0 | Quality |
| Pending Adjustments | Count | 0 | Efficiency |
| Open Alerts | Count | 0 | Compliance |
| Translation Completion | (Completed / Total Translations) × 100 | 100% | Coverage |
| Consolidation Readiness | Score (0-100) | > 80 | Speed |

## Category Groups
| Category | KPIs |
|---|---|
| Speed | Days to Consolidate, Consolidation Readiness Score |
| Quality | Elimination Rate, Unmatched IC Transactions |
| Efficiency | Adjustment Approval Rate, Pending Adjustments |
| Coverage | Entity Submission Rate, Translation Completion |
| Compliance | Audit Trail Completion, Open Alerts |

## Trend Indicators
| Trend | Meaning |
|---|---|
| improving | On track for targets |
| worsening | Below targets, needs attention |
| stable | Consistent performance |

## KPI Status
| Status | Meaning |
|---|---|
| onTrack | Meeting or exceeding target |
| atRisk | Below target but within acceptable range |
| critical | Significantly below target |
| exceeding | Exceeding target expectations |
