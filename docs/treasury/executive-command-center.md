# Executive Command Center

## Purpose

The Executive Command Center provides CFOs and Treasury executives with a single-pane-of-glass view into the entire treasury function, answering the key questions executives ask daily.

## Key Questions Answered

| Question | Answered By |
|---|---|
| What is our total cash position? | Cash Position Scorecard |
| Are we liquid enough? | Liquidity Scorecard + Health Overview |
| What payments are flowing? | Payment Summary |
| How many bank accounts do we have? | Bank Account Summary |
| Is our forecast accurate? | Forecast Summary |
| What is our risk posture? | Risk Summary + Insights |
| Which regions need attention? | Regional Overview |
| Which entities are performing? | Entity Overview |
| What currencies are we exposed to? | Currency Overview |
| How are our banking relationships? | Institution Overview |
| What needs immediate attention? | Alerts |
| What should we do next? | Recommendations |
| What's coming? | Roadmap |

## Health Score

The Treasury Health Score is a composite metric calculated from 6 categories:

```
health_score = (liquidity × 0.20) + (forecast_accuracy × 0.20) +
               (payment_success × 0.15) + (bank_health × 0.15) +
               (compliance × 0.15) + (cash_availability × 0.15)
```

| Score | Rating | Color |
|---|---|---|
| 90-100 | Excellent | Gold |
| 75-89 | Good | Emerald |
| 50-74 | Fair | Amber |
| <50 | Needs Attention | Red |

## KPI Section

15 executive KPIs in a responsive grid provide at-a-glance metrics for:
Total Cash, Available Cash, Restricted Cash, Global Liquidity, Net Cash Flow, Payments Today, Collections Today, Forecast Accuracy, Working Capital, Active Accounts, Banking Relationships, Legal Entities, Regions, Health Score, Days Cash Remaining.
