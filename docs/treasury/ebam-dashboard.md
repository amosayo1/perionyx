# eBAM Dashboard

## Overview

The eBAM Dashboard provides unified visibility into enterprise bank account governance. It answers: What accounts do we own? What needs attention? What is the health of our banking relationships?

## Tabs

| Tab | Purpose | Key Component |
|---|---|---|
| Overview | 12 KPI summary metrics | `BankAccountOverview` |
| Accounts | Full account registry | `EnterpriseAccountRegistry` |
| Banks | Bank relationship profiles | `BankRelationshipCenter` |
| Signatories | Authorized signatory registry | `AuthorizedSignatoriesGrid` |
| Mandates | Mandate management | `MandateManagementTable` |
| KYC | KYC compliance center | `KYCComplianceCenter` |
| Ownership | Entity hierarchy | `OwnershipHierarchy` |
| Lifecycle | Account lifecycle pipeline | `AccountLifecycleBoard` |
| Compliance | Compliance monitoring | `AccountCompliancePanel` |
| Analytics | 10 analytical charts | Chart components |
| Recommendations | AI-powered suggestions | `BankAccountRecommendationsPanel` |
| Alerts | Operational alert feed | `BankAccountAlertsPanel` |

## Executive Header KPIs

| Metric | Description |
|---|---|
| Total Accounts | All accounts across all entities |
| Active Accounts | Currently active and operational |
| Dormant Accounts | No activity beyond threshold |
| Restricted Accounts | Limited operation due to compliance |
| Closing Accounts | In closure process |
| Legal Entities | Entity count with accounts |
| Banking Partners | Unique banking relationships |
| Countries/Currencies | Geographic and currency coverage |
| Authorized Signatories | Total signing authority holders |
| Mandates Expiring | Approaching expiry within 30 days |
| KYC Pending | Incomplete or expired KYC |
| Compliance Alerts | Active compliance issues |

## Filters

15 filter dimensions: Region, Country, Legal Entity, Business Unit, Bank, Currency, Account Type, Ownership, Lifecycle Status, Account Status, KYC Status, Mandate Status, Risk Level, Date Opened, Signatory.
