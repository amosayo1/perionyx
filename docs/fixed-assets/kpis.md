# Fixed Assets KPIs

## Key Performance Indicators

| KPI | Formula | Target | Category |
|---|---|---|---|
| Total Assets | Count | — | Valuation |
| Total Cost | Sum of capitalized costs | — | Valuation |
| Net Book Value | Cost - Accumulated Depreciation | — | Valuation |
| Depreciation Rate | Accumulated Dep / Total Cost | < 40% | Depreciation |
| Maintenance Ratio | Maint Cost / Asset Value | < 5% | Maintenance |
| Asset Utilization | (Uptime / Total Time) × 100 | > 85% | Utilization |
| Fully Depreciated % | Fully Dep / Total Assets | < 10% | Compliance |
| Impairment % | Impaired / Total Assets | < 5% | Compliance |
| Disposal Gain/Loss | Net Proceeds - NBV | Positive | Efficiency |
| CapEx Variance | (Actual - Budget) / Budget | ±5% | Budget |
| Replacement Coverage | Replacement Value / Insured Value | > 90% | Risk |

## Category Groups
- **Valuation**: Total Cost, Net Book Value, Replacement Value
- **Depreciation**: Depreciation Rate, Avg Useful Life, Avg Remaining Life
- **Maintenance**: Maintenance Ratio, Preventive Ratio, Emergency Ratio
- **Utilization**: Utilization Rate, Downtime Hours, Cost per Hour
- **Compliance**: Fully Depreciated %, Impairment %, Revaluation Frequency
- **Efficiency**: Disposal Gain/Loss, CapEx Variance, Maintenance ROI
