**Platform scope**: 392 API routes, 67 modules, 338 Prisma models. 10 product domains, 12 platform pages, 11 security pages, 10 AI pages.

## Keyword Mapping Rules

### Rule 1: One Primary Per Page

Every page targets ONE primary keyword cluster. The primary keyword appears in:
- H1 (once, naturally)
- Title tag (first position)
- Meta description (naturally)
- URL slug (if applicable)
- First paragraph

### Rule 2: Secondary Keywords in H2s

Secondary keywords appear in H2 headings naturally. They support the primary keyword without competing with it.

**Example** for `/product/accounts-payable`:
- H1: Accounts Payable Automation Software (primary)
- H2: Three-Way Matching Engine (secondary: three-way matching)
- H2: Approval Workflow Automation (secondary: approval workflow)
- H2: Payment Processing (secondary: payment processing)
- H2: Vendor Management (secondary: vendor management)

### Rule 3: No Keyword Stuffing

Write for humans first. Keywords should appear naturally in context. If a sentence feels forced, rewrite it.

**Bad**: "Our accounts payable automation software automates accounts payable for enterprise accounts payable teams."
**Good**: "Automate your entire AP workflow — from invoice receipt to payment execution."

### Rule 4: Descriptive Anchor Text

Internal links use descriptive anchor text that includes keywords where natural.

**Bad**: "Click here to learn more about our AP solution."
**Good**: "See how our three-way matching engine works."

### Rule 5: Natural Language Variations

Use natural language variations of keywords. Google understands semantic relationships.

| Primary Keyword | Natural Variations |
|---|---|
| Accounts payable automation | AP automation, invoice processing, vendor payment automation |
| Treasury management | cash management, liquidity management, treasury operations |
| Approval workflow | approval chain, approval routing, approval process |
| Financial workflow automation | financial process automation, finance automation |
| Enterprise financial security | financial data security, enterprise security |
