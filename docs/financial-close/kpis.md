# Close KPIs

## Key Performance Indicators

| KPI | Formula | Target | Description |
|---|---|---|---|
| Days to Close | (Close Date - Period End) | < 7 days | Time to complete close |
| Task Completion | (Completed / Total) × 100 | 100% | Close task progress |
| Reconciliation Rate | (Completed Recons / Total) × 100 | 100% | Accounts reconciled |
| Approval Rate | (Approved / Total) × 100 | 100% | Approval completion |
| Open Exceptions | Count | 0 | Unresolved issues |
| Flagged Journals | Count | 0 | Journals needing review |

## Category Groups
- **Speed**: Days to Close, Task Completion Rate
- **Quality**: Reconciliation Rate, Unmatched Items
- **Efficiency**: Approval Rate, Approval Cycle Time
- **Compliance**: Open Exceptions, Flagged Journals

## Trends
- Improving → On track for targets
- Worsening → Below targets, needs attention
- Stable → Consistent performance
