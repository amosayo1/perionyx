# Compliance Obligations

## Types
- **Statutory**: Required by law (e.g., SOX 302 certification)
- **Regulatory**: Required by regulation (e.g., PCI DSS firewall config)
- **Contractual**: Required by contract (e.g., client data protection)
- **Internal**: Self-imposed (e.g., internal audit schedule)
- **Fiduciary**: Duty of care obligations

## Frequencies
one-time, daily, weekly, monthly, quarterly, semi-annual, annual, ad-hoc

## Statuses
compliant, non-compliant, partially-compliant, not-assessed, under-review, remediated

## Service
`ObligationService` provides CRUD + query by framework, type, status, department, and owner.
