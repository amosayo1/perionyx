# Executive Dashboard v2 — Enterprise Command Center

## Design Philosophy

The Executive Command Center transforms the flat financial dashboard into a mission-control experience. Every element is designed to answer one question: **"What is the state of the enterprise right now?"**

**Core principles:**
- **10-second comprehension** — An executive should understand the organization within 10 seconds of opening the dashboard
- **Information hierarchy** — Not a collection of widgets; a curated narrative with clear primary, secondary, and tertiary focal points
- **Purposeful data** — Every metric, chart, and card has a reason to exist; no decoration
- **Action-ready** — Insights lead to actions; recommendations are surfaced at the point of need
- **Calm confidence** — Visual design communicates stability, control, and readiness without noise

### Zone 1 — Executive Greeting
- Personalized greeting with time-of-day awareness
- Organization name, business unit
- Current date/time, accounting period
- Provides context and orientation

### Zone 2 — Executive KPIs
- 5 primary KPIs: Cash Position, Working Capital, Revenue (MTD), Operating Expenses, Business Health
- Each includes: value, trend (▲/▼/→), delta %, sparkline (30-day), status indicator, confidence %
- KPIs are the primary focal point — largest, most prominent

### Zone 3 — Timeline Preview
- Last 6 enterprise events across all modules (approvals, payments, risk, policy, treasury, automation, AI)
- Color-coded by type, with status badges
- "Open Executive Timeline" link to full timeline view

### Zone 4 — AI Executive Brief
- Today's AI-generated summary
- Top Risks section with amber indicators
- Top Opportunities section with green indicators
- Suggested Actions section with gold indicators
- "Open AI Briefing" link to full AI insights

### Zone 5 — Enterprise Health
- 6 scorecards: System Health, Financial Health, Treasury Health, Compliance, Operational Health, Workflow Health
- Circular progress indicators with percentage
- Overall Enterprise Health composite score at top
- Color-coded: healthy (green), warning (amber), critical (red)

### Zone 6 — Treasury Command Center
- 6 treasury metrics in compact grid: Total Cash, Bank Accounts, Liquidity Ratio, FX Exposure, Upcoming Payments, Forecast Confidence
- Treasury Risk Score progress bar
- "Open Treasury Center" link

### Zone 7 — Strategic Analytics
- Revenue trend line chart (6 months)
- Expense breakdown bar chart
- Status metrics: Approval Velocity, Month-End Progress, Forecast Accuracy
- Cash position sparkline (7 days)

### Zone 8 — Operational Intelligence
- Summary counters: Pending Approvals, Slow Processes, Automation Opportunities, Optimization Suggestions
- Active bottlenecks with severity indicators
- "Open Operations Center" link

### Zone 9 — Enterprise Recommendations
- Generated by Optimization Engine (Phase 8C.9)
- Each recommendation includes: impact badge (high/medium/low), confidence %, ROI, time saved, category
- "View All Recommendations" link

### Zone 10 — Quick Actions
- 9 action tiles in 3×3 grid: New Invoice, Payment, Transfer, Journal, Approval, Report, Customer, Supplier, Workflow
- Icon + label with hover scale animation

## Visual Hierarchy

| Level | Elements | Treatment |
|-------|----------|-----------|
| **Primary** | Executive KPIs (Zone 2) | Large metrics (2xl), bold, trend arrows, sparklines, status dots |
| **Secondary** | Enterprise Health, Treasury Command | Card-based with score rings, compact metrics grid |
| **Tertiary** | Timeline, AI Brief, Recommendations | Scrollable lists, compact items, action links |

## Card System

Every dashboard card (`DashboardCard`) supports:
- **Hover elevation** — subtle `scale(1.01)` + `y(-1px)` via framer-motion
- **Loading skeleton** — pulse animation with 3 skeleton bars
- **Empty state** — centered `Inbox` icon + descriptive message
- **Error state** — centered `AlertCircle` icon + retry button
- **Refresh animation** — spinning refresh icon on click
- **Context menu** — 3-dot menu on hover with pin/export/fullscreen options
- **Fullscreen mode** — `Maximize2`/`Minimize2` icon toggle
- **Pin** — pin icon, filled gold when pinned
- **Export** — download icon, triggers export handler

## Charts

All charts are custom inline SVG (zero external dependencies):
- **SparklineChart** — trend sparkline with gradient fill, configurable color/stroke/width
- **TrendLineChart** — multi-point trend line with axis labels, gridlines, gradient area fill, compact formatting
- **BarChart** — vertical bar chart with labels, gridlines, color per bar
- **DonutChart** — circular donut with segmented arcs, center label/value, legend
- **HealthScorecard** — circular progress ring with percentage, label, trend arrow, status color

## Performance Strategy

| Metric | Target | Strategy |
|--------|--------|----------|
| First paint | <500ms | Server Component data fetching, render-ready props |
| Layout shift | 0 | Fixed grid dimensions, skeleton placeholders |
| Animation budget | 16ms/frame | CSS transforms only (opacity, scale, translate) |
| Re-renders | Minimal | `memo` on every zone component, stable callbacks |
| Lazy loading | N/A (above fold) | All zones render on mount — critical dashboard |

| ≥768px (Tablet) | 2-column grid, side-by-side zones |
| <768px (Mobile) | Single column, full-width stacked zones |

## Accessibility

- **Keyboard navigation**: All interactive elements are reachable via Tab/Shift+Tab
- **Focus management**: Visible focus rings on cards, buttons, links
- **Reduced motion**: Respects `prefers-reduced-motion` via MotionProvider (existing)
- **High contrast**: All text meets WCAG AA contrast ratios on charcoal backgrounds
- **ARIA labels**: Refresh buttons, context menus, chart SVGs have descriptive labels
- **Screen readers**: Chart data is conveyed through `aria-label` on SVGs
