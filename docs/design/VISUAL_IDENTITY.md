# Visual Identity

**Phase 22.0B — Brand DNA**

Perionyx is enterprise financial infrastructure. Its visual identity communicates **precision, authority, and trust** — not consumer playfulness.

---

## Brand Essence

**Precision. Authority. Trust.**

Inspired by Bloomberg Terminal, Stripe Dashboard, Linear, Apple, and Mercedes S-Class interior. Dark surfaces, gold accents, restrained typography, zero noise.

## Color Rationale

### Gold (`#d4af37`)

The signature accent. Used sparingly for:
- Primary metric values (cash position, KPIs)
- Active states (selected nav item, focused input)
- Primary action buttons (Submit, Approve)
- Brand moments (logo, hero titles)

Gold is **never** used for:
- Backgrounds (except subtle tints at 8% opacity)
- Borders (except focus rings at 20% opacity)
- Decorative elements

### Backgrounds

Four surface levels, progressing from deep to elevated:
| Token | Hex | Usage |
|---|---|---|
| `SURFACES.base` | `#0a0a0f` | App background, sidebar, header |
| `SURFACES.raised` | `#111118` | Cards, panels, table rows |
| `SURFACES.elevated` | `#1a1a24` | Dropdowns, popovers, hover states |
| `SURFACES.floating` | `#222230` | Modals, dialogs, tooltips |

### Text

Three levels of text hierarchy:
| Token | Hex | Usage |
|---|---|---|
| `TEXT.primary` | `#f7f6f2` | Headings, metric values, primary content |
| `TEXT.secondary` | `#a1a1aa` | Body text, labels, descriptions |
| `TEXT.tertiary` | `#71717a` | Captions, timestamps, placeholders |

## Typography Rationale

### Inter

Clean, geometric, highly legible at small sizes. The workhorse of enterprise interfaces. Every text element in Perionyx uses Inter.

### JetBrains Mono

Monospaced font for:
- Financial numbers (cash positions, KPI values)
- Code blocks
- Tabular data requiring alignment

Monospaced fonts communicate **precision** — critical for financial audiences.

## Visual Tone

| Attribute | Perionyx Is | Perionyx Is NOT |
|---|---|---|
| Surface | Dark, matte, deep | Light, glossy, flat |
| Accent | Gold, restrained, purposeful | Rainbow, decorative, frequent |
| Typography | Clean, hierarchical, dense | Playful, decorative, sparse |
| Motion | Subtle, smooth, 200-400ms | Bouncy, springy, exaggerated |
| Layout | Dense, information-rich | Airy, consumer-friendly |
| Icons | Lucide, 20px, consistent | Custom SVGs, varied sizes |

## Logo Usage

The Perionyx logo uses the brand gold (`#d4af37`) on dark backgrounds. The logo should never appear on light backgrounds. Minimum clear space: 24px on all sides.
