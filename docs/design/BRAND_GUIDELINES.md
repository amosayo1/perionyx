# Brand Guidelines

**Phase 22.0B — Brand Usage Rules**

---

## Logo

### Primary Logo
- Gold (`#d4af37`) on dark background (`#0a0a0f`)
- Minimum clear space: 24px on all sides
- Minimum size: 32px height

### Logo Don'ts
- Never on light backgrounds
- Never with drop shadows or effects
- Never rotated or skewed
- Never recolored (only gold)

## Color Usage

### Gold (`#d4af37`)
**Use for:**
- Primary metric values
- Active/selected states
- Primary CTA buttons
- Brand moments (logo, hero titles)
- Key performance indicators

**Don't use for:**
- Backgrounds (except 8% opacity tint)
- Borders (except 20% opacity)
- Body text
- Decorative elements
- Secondary actions

### Backgrounds
- Always dark. No light mode.
- Surface progression: base → raised → elevated → floating
- Never use pure black (`#000000`) — always `#0a0a0f` minimum

### Text
- Three levels only: primary, secondary, tertiary
- Never use gold for body text
- Never use decorative fonts

## Typography

### Font Usage
| Context | Font | Weight |
|---|---|---|
| Headings | Inter | 600–700 |
| Body | Inter | 400–500 |
| Financial numbers | JetBrains Mono | 500–700 |
| Code | JetBrains Mono | 400 |
| Badges/Tags | Inter | 600 |

### Don'ts
- Never use more than 2 fonts in a single view
- Never use decorative/script fonts
- Never use font-size below 11px
- Never use ALL CAPS for body text (acceptable for labels in small caps)

## Spacing

- Always on the 4px grid
- Never hardcode pixel values
- Use semantic tokens (LAYOUT.cardPadding, not SPACE[5])

## Motion

- Subtle and smooth, never bouncy
- 200–400ms maximum duration
- Always respect prefers-reduced-motion
- Gold glow for emphasis only

## Voice & Tone

### Writing Style
- Direct and concise
- No jargon without explanation
- No marketing language in UI
- Active voice preferred

### Error Messages
- Explain what went wrong
- Suggest how to fix it
- Never blame the user

### Empty States
- Explain what belongs here
- Provide a clear next action
- Never show "No data" without context

## Photography / Imagery

- **No stock photography** — ever
- **No cartoon illustrations** — enterprise dignity
- **Diagrams use EDL tokens** — consistent visual language
- **Data visualizations ARE the imagery** — charts, graphs, metrics
