# FX Revaluation

## Rate Types

- **Historical** — Rate at transaction date
- **Spot** — Current market rate
- **Average** — Period average rate
- **Closing** — Period-end rate

## Revaluation Process

1. Identify foreign currency balances
2. Calculate unrealized gain/loss using current rate
3. Post revaluation journal
4. Track realized gains/losses on settlement

## Multi-Currency Support

- Functional currency (reporting)
- Transaction currency (original)
- Translation adjustments recorded to AOCI
