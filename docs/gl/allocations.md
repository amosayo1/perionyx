# Allocations

## Methods

- **Driver-based** — Allocate based on cost drivers (e.g., headcount, revenue)
- **Percentage** — Fixed percentage allocation
- **Headcount** — Allocate based on employee count
- **Revenue** — Allocate based on revenue contribution
- **Square Footage** — Allocate based on space usage
- **Manual** — Manual allocation amounts

## Allocation Lifecycle

1. Define allocation rule with source and target accounts
2. Execute allocation run for a period
3. Review allocation entries
4. Post allocation journals
5. Reverse if needed
