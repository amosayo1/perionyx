# Trial Balance

## Structure

Each trial balance entry contains:
- Account number and name
- Account category
- Beginning balance (debit/credit)
- Period activity (debit/credit)
- Ending balance (debit/credit)
- Net movement

## Dimensions

Trial balance can be viewed by:
- Entity
- Business Unit
- Region
- Currency
- Ledger
- Period
- Consolidated
- Comparative (period-over-period)
