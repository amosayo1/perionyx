# Intercompany Accounting

## Account Types

- **Due From** — Intercompany receivable
- **Due To** — Intercompany payable

## Settlement Status

- **Unsettled** — Balance not yet settled
- **Partial** — Partially settled
- **Settled** — Fully settled

## Elimination

Intercompany balances are eliminated during consolidation:
1. Match due from/due to between entities
2. Create elimination entries
3. Adjust consolidated financial statements
