# Executive Insights

## Overview

Executive Insights are AI-generated observations across 13 categories spanning the entire enterprise. Each insight includes severity, confidence, source domain, metrics, and actionable recommendations.

## Categories

| Category | Description |
|---|---|
| financial | Balance sheet, P&L, cash flow observations |
| operational | Process efficiency, automation opportunities |
| risk | FX, credit, market, operational risk |
| compliance | Regulatory, tax, policy compliance |
| treasury | Cash position, liquidity, banking |
| tax | VAT, corporate tax, transfer pricing |
| investments | Portfolio, yield, allocation |
| revenue | Revenue trends, growth, pipeline |
| cost | Operating expenses, cost optimization |
| fraud | Suspicious patterns, KYC gaps |
| anomaly | Statistical outliers, unusual patterns |
| forecast | Forward-looking predictions |
| recommendation | AI-generated action items |

## Insight Lifecycle

1. **New** — Detected by AI, awaiting review
2. **Reviewed** — Seen by human operator
3. **Acknowledged** — Accepted as valid
4. **Actioned** — Remediation in progress or complete
5. **Dismissed** — Rejected as false positive or irrelevant

## Severity Levels

| Level | Meaning | Response |
|---|---|---|
| Low | Informational | Monitor |
| Medium | Requires attention | Review within week |
| High | Significant impact | Review within 24h |
| Critical | Immediate threat | Immediate action |

## Confidence Levels

| Level | Meaning |
|---|---|
| Very Low | <20% — speculative |
| Low | 20-40% — weak signal |
| Medium | 40-60% — moderate confidence |
| High | 60-80% — strong signal |
| Very High | >80% — highly reliable |
